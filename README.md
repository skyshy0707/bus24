Проект ERP-системы свободной рассылки заявок маршрутов пассажирского транспорта.

Основная идея - расшаривание любого маршрута (идеи) как url из информационной системы `wikiroutes` между пользователями, зарегистрированных в проекте как `пассажирские АТП`.


Запуск как Backend так и Frontend:


```
docker compose up -d --build  
```

!NB Перед запуском создайте файлы переменных окружения с указаниями ниже.

Backend

Основные настройки backend/.env

DEBUG=[INTEGER] #Django settings
SECRET_AUTH_KEY=[HEX]

Опционально, можно изменить `SECRET_AUTH_KEY`, используемый при Bearer-аутентификации

Frontend

Архитектура - классический FSD с шестью слоями.

pages - основные страницы с монтирование виджетов моделей: `lead`, `message`, `profile`, `unit`.

widgets - помимо перечисленных выше, содежит вспомогательные:

    model-control-panel - с реализованными базовыми методами, пропсами для обеспечения 
    crud операций, который пользователь может совершать прямо в списке элементов (просмотр, удаление). Встраивается в корневой компонент проекта уровня widgets как миксин. 

    attach-detach-unitset* - UI для редактирования списка элементов, относящихся к модели.
    Встраивается как вложенный компонент. Главные пропсы:

     `model` - название модели - это ключевое, так как методы crud-операций в компоненте, куда вкладывается, будет приниматься исходя из этого параметра как delete[Model], 
     get[Model], или, в противном случае методы принимаются как заданные в компоненте как `delete_` и `view`.

     `where_emit` - название метода принимающий набор id с типом операции из { 'add', 'remove' }, производящий либо их добавление или удаление к/из объекту/а модели.

    *В нашем случае, я реализовал это исключительно для автобусов, относящихся к маршруту.

features

    attach-detach-unitset-btn - встраиваемая кнопка действия по добавлению/удалению автобусов маршрута. Встраивается как вложенный компонент для widgets/attach-detach-unitset

    credentials - набор кнопок и операций по регистрации/входу пользователя

    header - верхняя панель сайта

    sidebar - боковая панель сайта


entities - содержит компоненты с полями форм каждой бизнес-сущности

    model_component - компонент-менеджер, сопоставляющий имя модели компоненту с полями формы

shared - утилиты, вспомогательные компонеты

    scroll - листание, рендеринг элементов в списке: 

        - получение элементов через запросы к серверу (указывается:

            `endpoint` - конечная точка ,
            
            `ws`- параметры запроса клиента к вебсокету (если запросы идут на веб-сокет) - опционально
        )

        - стилизация элементов в списке (что задаётся:

            `enabledCrud` - нужно ли включать кнопки удаления и просмотра элемента,

            `itemView` - какое поле выбирается в качестве подписи на кнопке и стиль - опционально, 

            `labels` - для оформления поля выбора - поля:описание - опционально, 

            `select` - какое поле модели выступает в качестве элемента input и тип выбра (мультиселект или одно) - опционально,
        )

        - изменение списка на подмножество элементов (перемещение связанных в модель / удаление из модели) [что задаётся опционально:

            `enabledSubset` - включение кнопки по изменению основного списка, 

            `mark_element_action_as` - какими значками { 'add', 'remove' } помечать кнопки удаления элементов из основного списка
            'add' соответствует '+' - `вернуть в объект`, 'remove' соотвествует '-' `убрать из объекта` - прим.,

            `set` - список, чьи элементы удаляются/включаются из/в основной список элементов, полученных из запроса к серверу
        ]




Основные настройки frontend/src/.env.development

VITE_API_MODE=dev
VITE_DOMAIN=localhost:8715
VITE_API_HOST=http://${VITE_DOMAIN}
VITE_API_URL=http://${VITE_DOMAIN}/api
VITE_BASE_URL=/

`VITE_DOMAIN` - домейн прокси-сервера, куда приходят запросы от клиента
`VITE_BASE_URL` - домейн маршрутизатора, задаваемый для клиентских конечных точек
